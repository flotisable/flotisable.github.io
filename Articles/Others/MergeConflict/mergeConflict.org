* 何謂合併衝突 Merge Conflict
  merge conflict 這個詞我是從 git 知道的，這主要是在版本控制上，多個版本對同一個檔案改動時發生的衝突。
  如果只是簡單的多幾行、移動幾行、刪幾行，這樣的衝突版本控制是很容易解決的。
  需要手動處理的情況，多爲比較複雜的改動，這也是一個通常會建議一個版本不要包含太多改動的原因。
